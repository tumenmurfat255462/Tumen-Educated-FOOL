Tumen Educated FOOL — Personal Website

This package contains your original website with a refined midnight-blue / electric-blue custom cursor.

Files:
- index.html — page content and links (unchanged)
- style.css — original visual design plus reliable cursor styling
- script.js — smooth custom cursor and automatic footer year

Run:
Keep all three files in the same folder and open index.html in a modern browser.

Cursor behavior:
- Desktop/laptop with a mouse: glowing blue dot with a smooth-following ring; the ring subtly expands over interactive elements.
- Touchscreens and small/mobile layouts: native cursor behavior is retained and the custom cursor is hidden.
- If JavaScript is unavailable, the normal system cursor remains available.
